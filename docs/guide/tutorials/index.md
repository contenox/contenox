# Tutorials

Agent paths, shortest first. Each one ends with something running. The two gateway paths end with a client spending an allowance against a model you serve.

- [**Your first agent**](/docs/guide/tutorials/first-agent/) — one file, what contenox builds behind it, and where the knobs are
- [**A mission agent**](/docs/guide/tutorials/mission-agent/) — an agent you fire and walk away from, and the report it leaves
- [**An agent that files notes into Obsidian**](/docs/guide/tutorials/vault-agent/) — an MCP server you attach, scoped by an envelope
- [**A recurring job**](/docs/guide/tutorials/recurring-work/) — the same work on a schedule, with approvals that survive the wait
- [**Gateway: day one**](/docs/guide/tutorials/gateway-local/) — you run the models, your own tools use them through one endpoint with a key each
- [**Gateway for a team**](/docs/guide/tutorials/gateway-team/) — one server, one endpoint, a key per person with their own ceilings and meter

After the gateway setup, follow [**Gateway operations**](/docs/guide/gateway-operations/) for day-two service management, credential rotation, backup/restore and upgrades.
